# Sign-Language-AI-Translator
A real-time Sign Language translator combining computer vision and machine learning. Built with Python, OpenCV, and MediaPipe, the system extracts 126 3D hand landmarks from a webcam feed. A trained Random Forest Classifier maps these geometric coordinates to text instantly, achieving an exceptional 99.64% model accuracy.
